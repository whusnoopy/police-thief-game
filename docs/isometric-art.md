# 5.0.6 斜视素材、遮挡与几何约定

本页记录已接入游戏的斜视素材，不改变地图编码、逻辑占位或通行规则。编辑器、地图库和俯视游戏继续使用原绘本素材。

## 统一坐标与光照

- 沿用已验收的 80×40 菱形格、16 显示单位桥高。所有地面、建筑立面、桥面、栏杆和车辆均通过同一投影构造，保持 2:1 地面轴线。
- 普通道路为高度 0，桥面为 1，坡中为 0.5；水面为 -0.25、草坪为 0.125（当前相当于下沉 4、抬高 2 个显示单位）。这些仅为斜视显示起伏，不改变领域层高度或通行规则。物体的局部高度叠加在所在表面之上；坡道上的车身、车轮与阴影按各自局部位置的实际坡高绘制。
- 建筑的可见立面沿地图 S/E 轴，门和山墙朝 S；银行门廊、柱子与台阶使用相同坐标。显示朝向不新增“只能从门前进入”的规则。
- 光源固定，建筑 S 面较亮、E 面较暗，投影偏向画面右下。车辆每个方向重新投影几何，不旋转整张带有光照和阴影的图片。
- 当前无逐格移动动画：角色直接到达结算位置，路线提示沿共享边衔接。停在坡道时采用真实坡中高度，车辆随坡面倾斜。

## 素材目录

| 范围 | 当前实现 | 比例与连接约定 |
| --- | --- | --- |
| 草地、道路、河流与河岸 | `src/ui/isometric/terrainArt.js` | 略抬高的薄草坪及草簇、下沉连续水面与岸壁、道路边线；同类相邻边无内部侧壁 |
| 斑马线、信号、出生点、停车与井盖 | 同上及 `signalArt.js` | 灯头沿过街轴相向、正背面分开，杆脚参与前后排序；保留信号含义，地面标识沿投影平面绘制 |
| 桥面和四向坡道 | 同上 | 共用领域层连接掩码，16 种桥面拓扑按开口拼接；只有封闭边绘栏杆，桥体封闭，不暗示桥下道路 |
| 银行、警察局、基地、农场、建筑、工地和路障 | `src/ui/isometric/sceneryArt.js` | 共用立面、屋顶、窗户、台阶与固定光照；无需加载新的建筑图片 |
| 连续山脉 | 同上 | 相邻山格共用边中点、角点高度，山脊拼接；雪顶与明暗随固定表面方向绘制 |

`assetMetadata.js` 记录建筑高度、占地半径、门向/入口参考、角色尺寸与落脚点。建筑仍占一个逻辑格，元数据不改变寻路或设施事件。

`sceneModel.js` 将桥面和后栏杆放在同格角色之前，前栏杆独立放在角色之后；立杆按各自杆脚位置与角色交错；不同格仍按地图落脚点前后交错。没有将全部桥或全部角色放到同一个最前层。

## 地面起伏与过街灯

水面使用连续的下沉表面，只有接壤陆地的边绘岸沿；可见背岸绘出岸壁，连接草地时岸顶跟随草坪高度。桥体已有独立侧面，河岸不会向上包裹高架。相邻水格共用同一水位，不在内部绘岸壁。

草坪略高于普通路面，露出的前缘绘薄土层；七组小草簇带有深浅草叶，同类相邻格不绘内部土边。角色、车辆、可达框、反向点选和路径使用同一表面投影，路线在道路/草坪/水面交界连接两侧的边端点。

横向斑马线两端灯头朝 E/W，纵向朝 S/N，面向对端过街行人。灯具包括底座、立杆、灯壳和遮光罩，正面上红下绿，当前相位点亮对应灯孔；背面不透出灯光。立杆偏向斑马线侧肩，避免站在过街路线中央。信号对象保留所在格坐标，单独记录杆脚的排序位置，正确排列在同格人物前后；不接管点击。旧 `CROSSWALK` 按横向绘制。

触屏/触控笔使用原始落下位置做精确 DOM/表面命中，合成点击沿用此目标，避免浏览器将水面落点吸附至临近车辆。角色的实际主体点击仍代理到自身逻辑格。

## 大地图视野

`5.0.6` 复用本组素材，不再次修改比例。场景与投影按地图自身的 10×10 / 20×20 尺寸构建；20×20 每角三层削角，只生成 376 个地面及对应点击目标，以坐标查找角色地面，按有效格收紧投影边界（80×40 单格时地面包围框为 1360×680），不改变单格比例；20×20 默认约 112 CSS 像素宽单格，先定位首个小偷，用户拖动访问其他区域。“全图”是总览，“定位角色”回到选中或本回合角色；旧 10×10 保留既有适配。世界坐标锚点、遮挡和点选随同一缩放移动，窗口变化仍保存观察中心，四角操作面板不挤占地图宽度。

`5.0.7` 按最新界面反馈改为进入斜视游戏先以 100% 展示全图，不自动定位角色；“定位角色”仍可手动放大到上述局部视野。缩放、拖动及视图切换继续保留观察位置，重新开局恢复全图。

## 居中、比例与设施入口

建筑和路障以格子中心为基底原点，显示偏移为零。六类建筑沿两条平面轴保留 90% 尺寸，真实高度（包括屋顶、门柱、烟囱和支架）为原素材的 42%；路障平面同为 90%、高度为 48%。这些变换作用于实际绘制、阴影和入口，不仅修改元数据。允许局部遮挡后方，但不完整遮住其他格子；自动检查相邻八格及地图边角。山、草、水、桥和坡道保持既有形状与高度。

人物、动物和车辆的室外显示取原尺寸的 86%；过街灯以各自杆脚为原点缩小为 86%，方向与脚位不变。车辆仍由原几何投影后统一缩放，车身贴合桥坡。设施内步行人物为 43%，锚定变换后的门口；驾车为 77.4%，停靠建筑入口侧边。逻辑格和进入事件保持原规则。

## 遮挡轮廓与编号

`actorLayout.js` 统一给出绘制、点选、轮廓与提示的实际尺寸/锚点。`spriteAlpha.js` 对四张源图各取一次 128×128 透明样本，透明度大于 127 才算主体，排除透明四角和软阴影。车辆使用真实 SVG 车身，去除阴影。`occlusionGeometry.js` 读取实际投影后的面/线形状，只有绘制顺序在角色之后的主体才能成为遮挡物；工地和栏杆间隙保持透明。

`occlusionLayer.js` 在前景遮罩内绘制主体的彩色细轮廓和浅色外缘，选中改金色；完整遮挡时内部仍透明，可见部分不重画。编号、携款和押送标识独立置于前景，不随设施角色缩小。邻近提示错开并用连线标明来源，点击编号或实际被遮挡主体仍选择原角色，透明四角不抢相邻落点。位图失败时保留角色名称/编号，不以实心矩形代替轮廓。切换视图释放旧订阅，轮廓刷新合并到下一帧。

## 细节与绘制开销

本版按用户反馈在既定风格、朝向和大小上增加细节：屋瓦采用交错砖缝，窗户有浅色外框、深色内框、分格及反光，门有门槛和把手，银行有柱脚/柱槽及钱币徽记，警察局使用盾形徽记。工地加入砖缝、支撑和梯架，山体补充岩面明暗。车辆增加玻璃反光、雨刷、保险杠、车牌、门把手和轮毂，桥栏有反光段。

细线通过 `createPainter.strokes` 合并到 SVG 路径，沿用同一世界坐标投影。屋顶、窗户和车身细节随视口缩放保持清晰，不另增位图资源。

## 车辆朝向

游戏控制器用独立的 `unitDirections`、`vehicleDirections` 保存本局显示方向，地图及领域会话不增加方向字段。每次行动取最后一个普通四邻步确定方向，原地上/下车不改变方向，远距离井盖传送不猜测朝向；车辆停放或返回后为新空车保存本次方向。

方向会跨视图切换、回合和棋盘重建保留，重新开局重置。空车或尚无行动记录的车辆采用明确的默认 S 方向；坡道上的无记录车辆优先沿坡道轴。方向仅影响显示。

## 图片导出与回退

四张人物/动物资源由 `experiments/storybook/assets/` 的原始 PNG 确定性缩放、编码；未重新生成形象。总计 100,556 字节（约 98 KiB）。导出工具为 `scripts/export-isometric-actors.mjs`，需要另行安装 sharp 或将其模块目录作为第一个参数。普通开发、测试与构建直接使用已提交的 WebP，不依赖 sharp。

原有 14 张 192 像素 WebP 继续用于俯视显示，斜视新增四张 384 像素资源。建筑、桥梁、地面和车辆为内置 SVG 几何，不增加对应图片请求。位图加载失败时仍显示可辨认文字，编号、携款与押送标识保留。
