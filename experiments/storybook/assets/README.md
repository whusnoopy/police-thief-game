## 程序绘制内容

实现在 [visuals.js](../visuals.js) 与 [preview.css](../preview.css)：

- 草地、路面、水面、高架桥面：稳定纹理、四向相邻连接、外角和草地内角处理；桥面保持现有单层通行含义。
- 井盖、停车 P 标、两种方向斑马线与动态红绿灯、旧红绿灯兼容标记。
- P/T 出生点、角色编号与阵营底座、动物底座、携款/押送 SVG 角标。
- 可达范围、路线累计步数、上下车标签、图片失败后的文字回退。

不需要额外生成每种角色状态贴图：通过角色或车辆主体加角标组合。样板提供步行携款、驾车携款、步行押送、驾车押送和银行占位的 60 像素示例。
