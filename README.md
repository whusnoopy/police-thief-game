# police-thief-game

警察抓小偷地图编辑与棋盘游戏。

目标设备为 iPad mini 7 及更大的平板，常用 iPad Air 3，以及 1920×1080 或更大的电脑屏幕；不针对手机小屏幕优化。

开始游戏前会检查出生点出口、取钱与逃脱路线，以及多次抓捕需要的警察局。动物会定期回农场，避免永久堵路。浏览器存储失败时可以继续编辑，页面会提示尚未保存，并提供备份导出与重试保存。

编辑器支持鼠标左键、手指和触控笔拖绘，以及按一次拖绘撤销/重做（当前页面最多 50 次，切换地图后重置）。游戏提供行动结果、角色状态计数和车辆去向说明；平板点击落点后先预览再确认，电脑鼠标仍可直接点击移动。

地图库可导出全部地图或单张地图，也可导入备份 JSON（最多 5 MB）。导入会跳过重复内容、为冲突编号分配新编号，保留已有地图和当前编辑状态；损坏条目以原文保留。复杂路线在后台计算，计算期间仍可查看规则或返回编辑器。

山可以相邻组成山脉：新增山保留已有邻山，其余上下左右邻格自动铺草地，斜角不额外限制。草地缓冲可扩建为山；仍邻山的格子不能改成道路或设施。放置不会覆盖设施和出生点，拖绘山脉可整体撤销。

## 5.x 版本规划

当前开发版本为 `v5.0.8` 测试版（上一冻结版本 `v5.0.7` 为提交 `93193cf`）。游戏中可切换“俯视”和“斜视（测试）”，对局、选中角色和待确认路线保持不变。斜视采用已验收的 2:1 菱形格，并接入统一朝向的建筑、连续山脉、拼接桥面、四向坡道与车辆；汽车和警车朝向跟随行动最后一步，车身贴合所在桥面或坡面。人物和动物沿用绘本形象，斜视使用更清晰的 384 像素透明素材及统一比例与落脚点。 本版细化了屋瓦、门窗、柱子和车辆细节；选中后可直接点击其他可行动己方角色换人，再次点击已选角色或使用“取消选中”重选，保留本回合骰点。

进入斜视游戏默认以 100% 显示全图，20×20 支持放大至 500%，旧 10×10 为 250%。地图周围的空白处和不可点击地块支持按住鼠标左键拖动，100% 时也可平移；触屏可直接拖动，点击“全图”恢复总览，“定位角色”放大查看选中或本回合首个角色。可点击位置保留点选，拖动松手不会误执行行动。游戏默认使用斜视，仍可切换俯视；地图编辑器和地图库保持 2D。

斜视模式的地图占满浏览器视口，操作分布在四角：左上为居中的游戏名、模式、版本、规则入口和视角，右上为状态与缩放（无文字标题），左下为行动记录和路线确认，右下为掷骰及行动按钮。左上、左下和右下去掉标题栏，行动区域不再嵌套外框；所有面板保持显示，移除展开/收起。文字说明集中在规则弹窗，以浅色分隔线和右对齐图标、左对齐说明的两列排列。主要行动使用主题蓝色，结束/跳过回合弱化为次级按钮。行动记录去掉“刚才：”并分条显示，保留本局历史，回合间用浅线分隔；记录区限制高度、可滚动回看，新结果自动滚动至底部，新局清空。切回俯视或返回编辑会恢复原布局。

2D 编辑和游玩已支持四向上下桥：普通桥面不能直接连接地面，坡道箭头朝高端、反向可下桥，两侧封闭。方向可用四个按钮选择，或按 `R` 轮换；预览绿边表示地形相接，红边表示封闭。

新建地图采用新规则；含旧高架的地图须先“创建升级副本”，调整坡道，再“校验并完成升级”，原图保留。升级副本再次修改后需要重新校验，撤销/重做同时恢复相应状态。无高架的旧地图可继续游玩，也可创建升级副本。桥面已按 16 种连接绘制，前后栏杆分别排序；被遮挡的人物、动物与车辆显示彩色轮廓，选中时为金色，也可通过前景编号选择；携款和押送提示保持可见。设施内人物缩小在门口，车辆停靠入口侧边。

本版建筑和路障回到格子中央并适度降高，保留绘本细节；允许向后局部遮挡，但不把其他格子完全盖住。人物、车辆、动物及过街立杆灯缩小约 14%，山、草、水和高架桥的高度保持原样。

`5.0.y` 为测试版本，每次形成可验证的实现或修复后递增 `y`；完成整体验收后发布 `5.1.0`，后续正式修复使用 `5.1.y`。游戏版本与地图编码版本分别管理。具体阶段、规则约定和验收条件见 [5.x 斜视棋盘实施计划](docs/v5-isometric-plan.md)，实际完成情况见 [版本记录](CHANGELOG.md)。

2026-11-08：用户授权将连续行动、操作费用及本轮界面调整冻结为 `v5.0.7`，后续验证和界面微调在 `5.0.8` 完成，首次正式版仍为 `5.1.0`。操作费另扣、首次行动后锁定角色、驾车入警局后下车与交付各 1 点的口径已由用户确认。river-city 可玩性及放大后的玩法组织仍待重新考虑；详见 [后续显示与玩法扩展](docs/v5-next-mechanics-plan.md)。

新建地图默认 20×20，每角削去三层，共保留 376 个可用格。削角区不可编辑、通行或生成角色；旧 10×10 仍为完整方形。旧 10×10 按原尺寸继续编辑和游玩，也可在编辑器点击“扩展为 20×20 副本”：原图保留在地图库，旧区域居中新图第 6–15 行/列，外围增加道路（山边保持草地），检查新增路线后点击“校验并完成扩展”。尺寸变化不会增加行动点；旧图扩展保留其原行动规则。

2D 编辑器占满浏览器视口，左侧使用剩余宽高作为画布，标题、版本和工具放在右栏；右栏内容独立滚动，“开始游戏”固定在右下角并分隔；悬停橙色地图名条时出现笔形重命名入口（触屏常显）。撤销/重做与绘制/拖动、缩放在画布顶部按组排列；高架和连续行动的常驻说明框移除，升级及校验操作保留。按 `T`、分类编号、地块编号可选择画笔。在“高架桥设施”分类可按方向键直选四向坡道，也可用 `R` 轮换。按 `Esc` 退出快捷选择。游戏状态和阵营提示使用实际角色绘图，标题去掉 emoji。“全图”按可用宽高显示完整棋盘。编辑器提供“绘制 / 拖动”、放大缩小、“全图 / 原大小”和行列提示；20×20 默认每格 48 像素，拖动模式不绘制。俯视游戏的大地图也可滚动查看，地图库显示地图尺寸。地图保存、分享和备份保留尺寸及来源，20×20 使用新 `v5.` 编码；旧编码继续固定为 10×10。

20×20 已统一采用三层削角，斜视按剩余地块收紧画布边界；未沿用测试阶段的完整 400 格编码。旧 10×10 的地图和分享码保持原样。开发服务器 `/experiments/map-shape/` 仍可只读比较不同幅度，详见 [削角地图说明](docs/map-corner-shape-study.md)。

地图库的「系统自带地图」提供三张「双岸追缉」地图。高架与暗道采用单次行动，多人追逃与双警双贼采用连续行动。载入时创建可编辑副本。也可用 `?example=river-city`、`?example=river-city-many` 或 `?example=river-city-duel` 直接载入。

新建地图采用连续行动：一次掷骰后，首次行动前可换人，扣点后由同一角色继续使用余额，也可主动结束。每次移动合计整段路线的基础费用后向上取整。驾车走一格道路扣 1 点，连走两格道路也扣 1 点。行人和汽车均不可进入水面。上车、下车、银行取钱、警局交付在到位后各另花 1 点，驾车押送到警局先下车再交付，共 2 点。预览/取消不扣点，整轮结束才更新信号和动物。旧地图可在编辑器点击“创建连续行动副本”，原图与原规则保留；river-city 也可用此入口测试新机制，其地形与玩法尚未重新设计。

## Development

```bash
npm install
npm run dev
```

开发服务器默认由 Vite 提供，适合本地模块化开发与热更新。

本机浏览器打开 `http://localhost:4173/`。其他能连到本机的设备可打开启动时终端列出的 Network 地址。直接打开 `index.html` 无法完整运行模块和样式。

## Build

```bash
npm run build
```

构建产物输出到 `dist/`。

## Visual study

俯视显示使用绘本素材：编辑器、俯视游戏棋盘与地图库共用连续地形和主体图片，携款、押送、角色编号及路径独立叠加。这组发布资源为 14 张 192 像素 WebP，合计约 132 KiB；原始 PNG 不进入生产构建。

斜视游戏另外使用内置 SVG 地形、桥梁、建筑和车辆，以及 4 张 384 像素人物/动物 WebP（合计约 98 KiB）。开发服务器中的 `/experiments/isometric/` 提供 50 个素材检查样例，包括遮挡轮廓与设施入口、草坪、水体、两向过街灯、所有桥面连接、四向坡道和车辆视图，不读写地图库。坐标、素材来源和朝向约定见 [斜视素材说明](docs/isometric-art.md)。

绘本棋盘样板位于 `experiments/storybook/`：运行开发服务器后打开 `/experiments/storybook/`，可查看全部 14 张主体素材、试画连续地形与斑马线、切换驾车/携款/押送/银行占位场景，并查看现有规则计算的可达格和路线。样板使用独立示例，不读写玩家地图，也不进入默认生产构建。

评估、素材范围与后续正式接入步骤见 [视觉升级方案](docs/visual-upgrade-plan.md)。文件、尺寸和生成提示见 [素材目录](experiments/storybook/assets/README.md)。

## Deploy

当前生产部署方式改为上传 `dist/` 内容，而不是直接上传源码：

```bash
scp -r dist/* public_svr:~/police/
```

测试站构建使用 `VITE_MAP_STORAGE_NAMESPACE=police-test npm run build`，沿用 `/police-test/` 上现有的地图库存档。
