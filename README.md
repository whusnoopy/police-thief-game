# police-thief-game

警察抓小偷地图编辑与棋盘游戏。

目标设备为 iPad mini 7 及更大的平板（常用 iPad Air 3），以及 1920×1080 或更大的电脑屏幕；不针对手机小屏幕优化。

## 核心特性（5.x）

### 斜视棋盘与交互
- **固定相机 2:1 斜视棋盘**：游玩时棋盘占满浏览器视口，接入统一朝向的程序化 SVG 建筑、连续山脉、16 种拓扑拼接桥面、四向坡道、地面起伏与四向车辆；人物与动物沿用绘本形象（384 像素透明 WebP）。
- **遮挡轮廓与门口缩放**：建筑与路障居中降高，不完全遮住相邻格；被前景建筑、山体、桥栏或车辆遮挡的角色、动物与空车仅在遮挡处显示彩色轮廓（选中为金色），编号与携款/押送标识独立置于前景且可直接点选。设施内步行角色缩小在门口，车辆停靠入口侧边，逻辑位置仍为设施格。
- **视野与触控操作**：开局默认 100% 展示全图，20×20 支持放大至 500%（旧 10×10 至 250%）；空白或不可点击处可按住鼠标左键平移，触屏支持原生滚动。平板点击落点先预览再确认，电脑鼠标悬停预览、点击直接行动；首次实际扣点前可随时换人或取消选中。
- **四角面板布局**：左上为标题、规则弹窗、返回编辑、缩放与定位角色；右上显示当前回合、红绿灯相位与双方状态计数；左下为可滚动的分回合行动记录与路线确认；右下为掷骰与行动按钮。

### 玩法机制
- **20×20 三层削角地图**：新建地图默认 20×20、每角削去三层（共 376 个可用格）；旧 10×10 保持完整方形，可在编辑器创建 20×20 扩展副本。
- **连续行动与操作费用**：新建地图采用 `continuous` 连续行动规则——一次掷骰形成预算，首次实际扣点后锁定角色，可分段移动与操作或主动结束。每次移动合计整段路线的基础费用（道路步行 1、草地步行 2、道路驾车 0.5、高架/坡道 0.25）后向上取整扣点；上车、下车、银行取钱、警局交付在到位后各另付 1 点（驾车押送到警局先下车 1 点再交付 1 点），抓捕、逃脱不另收费，井盖传送保持 1 点。红绿灯与农场动物只在完整警察回合结束后更新一次。
- **四向上下桥与封闭水面**：高架桥仅通过四向坡道（箭头朝高端，双向通行、两侧封闭）连接地面陆上可驾车格；行人和汽车均不可进入水面。
- **同步与方向红绿灯**：20×20 地图可在编辑器勾选“南北向与东西向红绿灯交替”（开局南北向通行，每轮警察回合结束切换）。相邻同向斑马线沿行人通行轴合并，仅在外侧两端显示信号立杆；已停在斑马线上的单位遇变灯后，可沿原通行轴离开当前（含相邻合并的）斑马线，进入另一条斑马线仍需绿灯放行。
- **开局校验与后台寻路**：开局前校验出生点出口、取钱与逃脱路线、多小偷抓捕能力与坡道接法；农场动物受困 3 轮或停留 6 轮后回场避免永久堵路；寻路优先在 Web Worker 中计算，大地图在 Worker 不可用时使用同规则分批协作回退。

### 2D 编辑器、地图库与兼容
- **全视口 2D 编辑器**：左侧为可缩放/拖动棋盘（默认每格 48 像素），顶部为撤销/重做（最多 50 步）、绘制/拖动与缩放工具组；右侧为独立滚动的地块面板与固定右下角的「开始游戏」。支持鼠标、手指和触控笔拖绘、山脉连续构筑与草地缓冲、悬停笔形图标重命名当前地图，以及 `T` + 分类/地块编号、方向键/`R` 选坡道、`Esc` 退出的快捷操作。
- **系统自带地图**：地图库提供两张 20×20 连续行动内置地图——「双岸追缉 · 多人追逃」（`?example=river-city-many`）与「双岸追缉 · 双警双贼」（`?example=river-city-duel`），载入时创建独立可编辑副本。
- **旧图兼容、分享与备份**：游戏版本与地图编码版本（`v5.` / `v4.` / `v3.` / `v2.` / legacy）分别管理。旧 10×10 与单次行动地图可继续查看和编辑；含旧高架的地图须先创建升级副本并完成校验，也可显式创建 20×20 扩展副本或连续行动副本，原图始终保留。重命名同步更新分享码内的地图名，分享链接自动精简已完成的历史升级快照与默认设施字段；地图库支持整库/单图 JSON 导出与导入（最多 5 MB，按地图内容去重），存储失败或遇到损坏记录时保留原文并支持导出与重试保存。

设计规划、实现机制与历史阶段记录见 [5.x 斜视棋盘实施计划](docs/v5-isometric-plan.md)、[5.0.5 之后扩展记录](docs/v5-next-mechanics-plan.md)、[规则与实现备忘录](docs/game-rules-implementation-memo.md) 和 [版本记录](CHANGELOG.md)。

## Development

```bash
npm install
npm run dev
```

开发服务器默认由 Vite 提供，支持局域网访问。本机打开 `http://localhost:4173/`，其他同局域网设备打开终端显示的 Network 地址。

## Build

```bash
npm run build
```

构建产物输出到 `dist/`。

## Test

```bash
npm test
```

自动测试覆盖地图编码/紧凑序列化与名称同步、旧图升级/扩展保护、三层削角、编辑历史与快捷键、启动与存档恢复、斜视投影/增量更新与遮挡轮廓、合并斑马线清场与方向灯、四向坡道、连续行动预算、NPC、停车回库，以及同步/Worker/协作回退的一致性。

运行 `npm run benchmark` 可测量复杂高架桥场景的寻路耗时；历史性能与浏览器检查记录见 [验证记录](docs/improvement-plan.md)。

## Visual Study

- **2D 编辑器与头像素材**：位于 `src/assets/storybook/`，包含 10 张 192 像素透明 WebP（合计约 91 KiB），服务于编辑器棋盘、调色板、地图库缩略图与回合/胜利头像；原始 PNG 不进入生产构建。
- **斜视素材**：地面、桥梁、建筑与车辆为内置程序化 SVG；人物与动物位于 `src/assets/isometric/`（4 张 384 像素透明 WebP，合计约 98 KiB）。开发服务器 `/experiments/isometric/` 提供 50 项独立素材与遮挡检查样例，不读写玩家地图库。详情见 [斜视素材约定](docs/isometric-art.md)。
- **历史设计实验页**：`/experiments/storybook/`（v4.0 绘本样板）与 `/experiments/map-shape/`（0–5 层削角只读比较，见 [削角地图说明](docs/map-corner-shape-study.md)）仅用于本地开发查阅，不进入生产构建。

## Deploy

正式站运行在 `aly02`，部署 `npm run build` 生成的 `dist/` 内容到 `~/www/police/`，再访问 [正式站](https://yewen.pro/police/) 验证。

```bash
rsync -a dist/assets/ aly02:~/www/police/assets/
rsync -a dist/index.html aly02:~/www/police/index.html
```

同一浏览器和同一 HTTPS 域名下，正式站首次打开时会将原测试站的地图库合并进正式地图库；编号冲突的地图会另存一份，测试存档原文保留。跨设备迁移可使用地图库的 JSON 导出与导入功能。
